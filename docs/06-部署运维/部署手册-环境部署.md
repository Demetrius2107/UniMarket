## 1. 环境总览

| 环境 | 用途 | 说明 |
|------|------|------|
| 本地开发 | 日常开发调试 | Docker Compose 一键起中间件，应用本地 IDE 启动 |
| 演示环境 | 联调/演示 | 单机部署（中间件 + 应用同一台机器） |

**拓扑**（源自 SDS §11）：

```
Nginx(:80/443) 前端SPA + API 反向代理
  └── Spring Boot App(:8091)  ← Nacos 注册
        ├── MySQL(:3306)     ├── Redis(:6379)
        ├── RabbitMQ(:5672)  ├── Elasticsearch(:9200)
        ├── Canal(:11111)    ├── XXL-Job(:9090)
        └── Nacos(:8848)     ├── Prometheus(:9090) + Grafana(:3000)
```

## 3. 基础设施部署（docker-compose）

### 3.1 目录约定

```
uni-market/
└── docs/
    └── docker/
        ├── docker-compose-infrastructure.yml   # 中间件编排
        └── .env                                # 端口/密码等环境变量
```

### 3.2 compose 模板（关键服务，端口/密码经 .env 注入）

```yaml
# docker-compose-infrastructure.yml
services:
  mysql:
    image: mysql:8.0.32
    container_name: unimarket-mysql
    ports: ["${MYSQL_PORT:-3306}:3306"]
    environment:
      MYSQL_ROOT_PASSWORD: ${MYSQL_ROOT_PASSWORD:-root123}
    volumes:
      - ./data/mysql:/var/lib/mysql
      - ./sql:/docker-entrypoint-initdb.d        # 首次启动自动执行建库建表
    command: --character-set-server=utf8mb4 --collation-server=utf8mb4_unicode_ci

  redis:
    image: redis:6.2
    container_name: unimarket-redis
    ports: ["${REDIS_PORT:-6379}:6379"]
    command: redis-server --requirepass ${REDIS_PASSWORD:-redis123} --appendonly yes

  rabbitmq:
    image: rabbitmq:3.12.9-management
    container_name: unimarket-rabbitmq
    ports: ["5672:5672", "15672:15672"]
    environment:
      RABBITMQ_DEFAULT_USER: ${RABBITMQ_USER:-unimarket}
      RABBITMQ_DEFAULT_PASS: ${RABBITMQ_PASS:-unimarket123}
      RABBITMQ_DEFAULT_VHOST: unimarket

  nacos:
    image: nacos/nacos-server:v2.2.3
    container_name: unimarket-nacos
    ports: ["8848:8848"]
    environment:
      MODE: standalone
      NACOS_AUTH_ENABLE: "false"

  elasticsearch:
    image: elasticsearch:7.17.14
    container_name: unimarket-es
    ports: ["9200:9200"]
    environment:
      discovery.type: single-node
      ES_JAVA_OPTS: "-Xms512m -Xmx512m"

  canal:
    image: canal/canal-server:v1.1.7
    container_name: unimarket-canal
    ports: ["11111:11111"]
    environment:
      canal.instance.master.address: mysql:3306
      canal.instance.dbUsername: root
      canal.instance.dbPassword: ${MYSQL_ROOT_PASSWORD:-root123}

  xxl-job-admin:
    image: xuxueli/xxl-job-admin:2.4.1
    container_name: unimarket-xxljob
    ports: ["9090:9090"]
    environment:
      PARAMS: "--spring.datasource.url=jdbc:mysql://mysql:3306/xxl_job?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai"

  prometheus:
    image: prom/prometheus:v2.47.2
    container_name: unimarket-prometheus
    ports: ["9091:9090"]                        # 宿主 9091 避免与 xxl-job 冲突
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml

  grafana:
    image: grafana/grafana:10.2.0
    container_name: unimarket-grafana
    ports: ["3000:3000"]

  kibana:
    image: kibana:7.17.14
    container_name: unimarket-kibana
    ports: ["5601:5601"]
```

### 3.3 启动步骤

```bash
cd docs/docker
docker compose up -d          # 一键拉起全部中间件
docker compose ps             # 检查健康状态（STATUS 为 Up/healthy）
```

> 首次启动 MySQL 会执行 `./sql` 下全部 DDL（建库建表 + 基础配置数据）。
> 变更 SQL 后需 `docker compose down && docker compose up -d` 或手动执行增量脚本（volumes 数据已持久化）。

## 4. 应用部署

### 4.1 构建

```bash
mvn clean package -DskipTests
# 产物：uni-market-app/target/uni-market-app-1.0.0.jar
```

### 4.2 配置（Nacos）

- 应用配置（数据源/Redis/MQ 等）统一放 Nacos：`unimarket-dev.yml`（见《配置规范-Nacos配置清单》）。
- 本地直连可用 `application.yml` 兜底（连接本机 Docker 映射端口）。

### 4.3 启动（本地开发）

```bash
# IDE：启动 uni-market-app 的 Application 类（dev profile）
# 或命令行
java -jar uni-market-app/target/uni-market-app-1.0.0.jar \
     --spring.profiles.active=dev
```

### 4.4 启动（演示环境，jar 方式）

```bash
nohup java -Xms512m -Xmx1024m -jar uni-market-app-1.0.0.jar \
  --spring.profiles.active=prod > logs/app.log 2>&1 &
```

### 4.5 Nginx 反向代理（模板）

```nginx
server {
    listen 80;
    server_name localhost;

    # 前端静态资源
    location / {
        root /opt/unimarket-front/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API
    location /api/ {
        proxy_pass http://127.0.0.1:8091;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

## 6. 内网穿透联调

第三方（微信 OAuth、支付宝异步回调、快递鸟回调）需公网可达的回调地址：

```bash
# natapp 示例：本地 8091 → 公网 https://xxx.natapp.cc
natapp -authtoken=<token> -localport=8091

# 或 frp 示例（frpc.ini）
[web]
type = http
local_port = 8091
custom_domains = unimarket.example.com
```

**配置约定**：
- 回调地址配置为 `https://<公网域名>/api/v1/order/alipay_notify` 等。
- 回调地址写入 Nacos 配置（`pay.callback-base-url`），不硬编码。
- 微信公众平台/支付宝开放平台后台配置回调域名与白名单 IP。

| 配置项 | 本地默认 | 说明 |
|--------|----------|------|

| 快递鸟 | 测试 key | 商户 ID + API key |

## 8. 启动检查清单与排障

### 8.1 启动后检查

- [ ] `docker compose ps` 全部 Up/healthy
- [ ] Nacos 控制台 `localhost:8848/nacos` 可登录，应用已注册（服务列表出现）
- [ ] XXL-Job 控制台 `localhost:9090/xxl-job-admin` 执行器在线
- [ ] Grafana `localhost:3000` 数据源连接 Prometheus 正常
- [ ] 健康检查：`curl http://localhost:8091/api/v1/health` 返回 200
- [ ] 冒烟：登录/商品列表/下单接口可用

### 8.2 常见排障

| 症状 | 排查方向 |
|------|----------|
| 应用启动失败，连不上 MySQL/Redis | 检查容器端口映射、密码、Nacos 配置 |
| 容器状态 Restarting | `docker compose logs <svc>` 看具体错误 |
| 回调收不到 | 检查内网穿透域名、回调地址配置、防火墙 |
| ES 索引空 | 检查 Canal 是否启动、binlog 配置、同步任务 |
| 任务不执行 | 检查 XXL-Job 执行器注册、任务分组 |
| 时区/编码问题 | 统一 `serverTimezone=Asia/Shanghai`、utf8mb4 |
