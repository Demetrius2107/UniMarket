# ADR-04：前端技术栈不限定（React / Vue 均可）

- **状态**：已接受（Accepted）
- **日期**：2026-08-10
- **关联文档**：《PRD》附录 C、《设计文档-SDS》§5
- **影响范围**：C 端与 ERP 前端

## 背景

PRD 对前端不设限定，项目以全栈单人开发，前端选型应基于个人熟练度与生态成熟度。

## 决策

**不限定单一框架**，推荐二选一：

- **React + Ant Design Pro**：组件生态丰富，AntD 表单/表格对 ERP 后台开发高效。
- **Vue3 + Element Plus**：上手曲线低，中文文档完善，适合快速开发。

抽奖动画推荐 **Lottie / Canvas**；移动端适配微信内置浏览器（H5/SPA）。

## 后果

- 正面：按开发者熟练度选型，效率最大化；两大生态均可支撑商城与后台。
- 负面：技术栈不统一可能带来切换成本（本项目单人开发，风险可控）。

## 备选方案

- 原生小程序：覆盖微信生态但跨平台成本高，与 H5/SPA 定位冲突。
- 服务端渲染（SSR）：SEO 友好但对纯 C 端商城收益有限。

## 约定

无论选型，必须遵循《前端开发规范》：目录结构、组件规范、接口对接（`/api/v1` + `Response<T>`）、构建产物交付 Nginx。
