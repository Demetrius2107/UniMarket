## 1. 总体原则

| 原则 | 说明 |
|------|------|
| 默认拒绝 | 未明确允许即为拒绝（白名单思维） |
| 纵深防御 | 前端校验 ≠ 后端安全，后端必须独立校验 |
| 最小权限 | 接口/数据/配置按需授权，禁止超集权限 |
| 数据校验在边界 | 所有外部输入（HTTP/回调/MQ）都视为不可信 |
| 安全左移 | 编码阶段就规避，不依赖上线后扫描补救 |

**信任边界**：HTTP 请求、第三方回调、MQ 消息、配置文件均视为不可信输入。

## 2. 注入防护（SQL/命令/模板）

### 2.1 SQL 注入

- MyBatis 一律 `#{}` 参数绑定，**禁止 `${}`** 拼接用户输入。
- 动态排序/动态字段：白名单映射，禁止直拼。

```java
// ❌ 禁止：用户可控字段拼接
// ORDER BY ${sortField}

// ✅ 白名单映射
private static final Map<String, String> SORT_WHITELIST = Map.of(
    "price_asc", "price ASC", "price_desc", "price DESC", "sales", "sales DESC");
String orderBy = SORT_WHITELIST.getOrDefault(sort, "create_time DESC");
```

### 2.2 命令注入

- 禁止 `Runtime.exec`/`ProcessBuilder` 拼接用户输入执行系统命令。
- 如需执行命令，参数数组传递 + 白名单校验。

### 2.3 模板/表达式注入

- 禁止用用户输入直接拼 SpEL/OGNL 表达式求值。
- 规则引擎（决策树）配置仅限后台可信来源，导入校验。

### 2.4 反序列化

- 禁止反序列化不可信数据到任意类（防止 RCE）；JSON 解析用白名单类型。

## 3. 越权防护（水平/垂直）

### 3.1 水平越权（用户间）

- 资源归属校验：查询/操作他人资源必须比对 `userId`。

```java
// 禁止：直接按前端传入 id 查询
Order order = orderRepository.queryByOrderId(orderId);

// 正确：绑定当前用户
Order order = orderRepository.queryByOrderIdAndUserId(orderId, currentUserId());
if (order == null) {
    throw new BizException(ErrorCode.NOT_FOUND);
}
```

### 3.2 垂直越权（角色间）

- ERP 后台接口校验运营角色（`role`），普通用户 Token 访问返回 403。
- 接口权限注解 + 拦截器统一校验，禁止在业务方法里散落判断。

### 3.3 禁止依赖

- 禁止信任前端传入的 `userId`、`role` 等身份字段，一律从 Token/会话上下文获取。

## 4. 认证与会话安全

| 项 | 约定 |
|----|------|
| Token | JWT：签名算法 HS256/RS256，过期时间必设，密钥强度足够且不入库不入日志 |
| 传输 | 生产必须 HTTPS；登录与支付接口禁止明文 HTTP |
| 存储 | 服务端不存 Token 明文（无状态 JWT）；如服务端会话则存哈希 |
| 密码 | 系统内密码（若有）必须 BCrypt 等加盐哈希，禁止 MD5/SHA1 裸存 |
| 注销 | 支持 Token 失效/黑名单（Redis），用户冻结时立即失效 |
| 轮询接口 | 登录轮询等接口限流（见《接口开发规范》§10） |

## 5. 敏感信息与数据安全

| 数据 | 处理 |
|------|------|
| 密码/密钥/私钥 | 环境变量/配置中心注入，禁止入库入日志入仓库 |
| 手机号/身份证/银行卡 | 展示与日志脱敏（`SensitiveUtil`），库内按需加密 |
| openId/unionId | 视为敏感标识，响应不随意返回 |
| 支付回调报文 | 日志脱敏（签名/敏感字段打码） |
| 配置模板 | `.example` 占位入库，真实值不入库（.gitignore 已排除） |

**加密约定**：
- 传输加密：HTTPS（全链路）。
- 存储加密：敏感字段 AES 加密存储（密钥走 KMS/环境变量）。
- 哈希：密码/Token 用 BCrypt；验签用 RSA2/SHA256-RSA。

## 6. XSS 与输出编码

| 场景 | 措施 |
|------|------|
| 富文本（商品描述/评论/消息） | 后端白名单清洗（HTML 标签/属性过滤），禁止原样入库回显 |
| 普通字段回显 | 前端转义 + 后端响应编码（`<` `>` `&` 等） |
| 文件名/URL 回显 | 校验协议白名单（`http/https`），禁止 `javascript:` |
| Header 注入 | 用户输入进 Header（如自定义字段）做 CRLF 过滤 |
| CSP | 前端配置 CSP 响应头（如可配），减少 XSS 影响面 |

**约定**：后端永远不信任前端已转义；回显数据按需二次清洗。

## 7. 文件上传与下载

| 项 | 约定 |
|----|------|
| 类型 | 白名单扩展名 + MIME 校验（图片/文档），禁止可执行文件 |
| 大小 | 单文件 ≤ 5MB（按业务），超限拒绝 |
| 存储 | 重命名存储（UUID + 原后缀），禁止使用用户文件名落盘 |
| 路径 | 存储路径不可由用户输入拼接（防目录穿越 `../`） |
| 下载 | 文件名响应头 URL 编码，Content-Disposition 防注入 |
| 图片处理 | 上传后重新编码（去 EXIF/脚本内容）防图片马 |

## 8. 外部依赖与第三方调用安全

| 项 | 约定 |
|----|------|
| 依赖漏洞 | 定期扫描（OWASP Dependency-Check / CI 门禁），高危必升 |
| 第三方回调 | 必须验签（微信/支付宝/快递鸟），验签失败拒绝并告警 |
| 回调 IP 校验 | 有条件时校验回调来源 IP/证书指纹 |
| 外部请求 | 统一超时（连接 3s/读 5s），防外部拖垮内部 |
| SSRF | 禁止代理用户输入的 URL 抓取内网资源；URL 解析校验协议与域名白名单 |

## 9. 加密与签名

| 场景 | 算法/密钥 |
|------|-----------|
| 支付验签（支付宝） | RSA2（SHA256withRSA），支付宝公钥 |
| 微信支付 | APIv3 密钥 + 平台证书验签，AES-256-GCM 解密回调 |
| JWT 签名 | HS256/RS256，密钥 ≥ 256bit，不入代码 |
| 存储加密 | AES-256-GCM，密钥 KMS/环境变量 |
| 密码哈希 | BCrypt（cost ≥ 10） |

**密钥管理**：密钥禁止硬编码、禁止提交仓库、禁止打日志；统一从环境变量/密钥管理获取（见《配置规范-Nacos配置清单》§6）。

## 10. 安全评审检查清单

代码评审/上线前检查：

- [ ] 无 `${}` 拼接 SQL、无动态排序直拼、无命令拼接
- [ ] 资源访问绑定当前用户 userId，无水平越权
- [ ] ERP 接口有角色权限校验，无垂直越权
- [ ] Token/密钥/私钥不入库、不入日志、不入仓库
- [ ] 手机号等敏感字段展示/日志已脱敏
- [ ] 富文本已白名单清洗，输出已编码（XSS）
- [ ] 文件上传类型/大小/重命名/路径穿越已防护
- [ ] 第三方回调验签通过，外部请求有超时
- [ ] 密码 BCrypt，支付验签 RSA2/APIv3，无弱算法
- [ ] 依赖漏洞扫描无高危未处理项
